# Task 4 - REST API with Flask

## Objective

Create a REST API that manages user data using Python and Flask.

## Technologies Used

- Python
- Flask
- Postman
- REST API
- JSON

## API Operations

GET - Get users

POST - Add a user

PUT - Update a user

DELETE - Delete a user

## API URL

http://127.0.0.1:5000/users
